# 概念图解模板库

用途：讲一个"结构"（循环、层级、因果、对比、分类……）时选哪种图解、怎么画、别犯哪些错。图解是 `components.md` T3 编号图里的一族；什么时候配图解、和插画怎么交替，见 `SKILL.md` 第一节。12 种模板都已在 `kit/diagrams.js` 实现（`VL.diagram.cycle / nested / flow / quadrant / compare / timeline / tree / venn / balance / network / spectrum / stack`），写法和参数见 `kit/README.md` 第九节，**以它为准**。

用户最看重的就是这类图：循环图、嵌套圈这种，**每个节点有名字 + 一行具体例子，图注写"为什么"，能点一层看一层，标签在图外用引线。**

## 一、所有图解共守的画法

| # | 规则 | 怎么做 | 正例 / 反例 |
|---|---|---|---|
| 1 | 节点 = 名字 + 一行例子 | 名字 ≤6 字粗体；下面一行具体例子 ≤14 字（"秒级：按键跳一下"），不写抽象释义 | 正例：AI `ch07-learning-as-search.html` 变异→选择→遗传，"每件事下"写了例子；反例：只有"行动 / 反馈 / 奖励"三个词的圈，读者看了不知道指什么 |
| 2 | 颜色分工 | 结构（框、箭头、轴）用墨色 `--dg-ink`；**全图只一个强调色**给当前要看的那一块（选中态 `--dg-hi`）；节点底色 `--dg-c1…c6` 用色号 `c` 分类，不按节点轮换颜色；对错用 `--ok/--no` 并加 ✓✗；量用 `--q1…--q6`，和正文、公式同色 | 反例：每个节点一种颜色、五颜六色（AI 用户反馈"像 AI 拼的"） |
| 3 | 标签在图外，用引线 | 嵌套圈、同心椭圆、曲线旁的说明，放在图形外侧，用细引线（1–1.5px）连到所指部位；不把字塞在边框上 | 正例：GD `ch02-core-loop.html` 三层嵌套循环"右侧用引线标出每一层" |
| 4 | 文字离线 ≥4px | 文字包围盒离任何框、线、圈 ≥4px；挤不下就加高画布，不缩字 | `tools/qa.mjs` 的图内文字检查（出界、压边框、挤线、重叠）在 GD 课抓出过几百处 |
| 5 | 图中字 ≥13px，对比度 ≥4.5:1 | 手写体可用于图中文字，但要验证过清晰，字母数字另配清晰字体（`unicode-range`） | 反例：GD 早期手写体"VR5"被看成"9R5" |
| 6 | 图注写"为什么" | 图注说这张图证明 / 说明了什么，不复述图里的字；≤40 字 | ✓"秒、分、天三层套在一起，所以一局玩腻了还有更大的圈拉你回来"；✗"核心循环的三个层级" |
| 7 | 可点就能点一层看一层 | kit 的图解默认可选：点中的块高亮、其余变淡，信息行换成这块的 `info`；键盘、`select:false`、事件见 `kit/README.md` 第九节 | 正例：AI `ch01-what-is-ai.html` 套娃图"点任意一层，看它比外层多了什么" |
| 8 | 静态版信息完整 | 不点也能读懂；点开只是放大细节。打印、关掉动效时全部可见 | — |
| 9 | 有 `aria-label` | 写清画了什么、怎么连（读屏读者靠它）；颜色不是唯一信息。kit 的图解不给 `label` 时自动生成 | 正例：GD 每张内联图都有完整 `aria-label` |
| 10 | 和正文同宽，约 2:1，高 ≤300px | 节点多时宁可拆成两张，不缩小 | — |
| 11 | 边缘：概念图可随皮肤手绘抖动，数据图笔直 | 抖动滤镜 `in="SourceGraphic"`，文字放滤镜组外 | DS 项目规则：数据图 `o.wob = 0` |

## 二、模板

### 1 循环
- **讲什么**：一件事的结果又成为下一轮的起点——反馈回路、核心循环、迭代、学习循环、恶性循环。
- **三课例子**：GD `ch02-core-loop.html`（行动→反馈→奖励→成长→新目标）、`ch04-rules-mda.html`（大富翁正反馈）、`ch17-goodhart-metrics.html`（恶性循环）、`ch26-prototype-iterate.html`（迭代循环）、`ch29-build-web-game.html`（游戏循环）；AI `ch06-reinforcement-learning.html`（强化学习循环，用开场喂零食来标）、`ch05-supervised-unsupervised.html`（k-means 认旗 / 挪旗循环）。
- **画法**：3–6 个节点沿圆或圆角矩形排；箭头首尾相接，回到起点的那一段画粗或加 ↺ 标；节点 = 名字 + 用本章开场例子的一行（AI `ch06` 的做法最好：循环的每一步都用"喂零食"那个场景来标）。正反馈 / 负反馈在箭头上标 + / −。
- **常见错误**：节点超过 6 个，圈变成一串字；所有箭头一样粗，看不出哪里是回路；节点只写抽象词。

### 2 嵌套圈 / 套娃
- **讲什么**：A 包含 B、B 包含 C；或同一个模式在不同时间尺度上嵌套。
- **三课例子**：AI `ch01-what-is-ai.html`（人工智能 ⊃ 机器学习 ⊃ 深度学习 ⊃ 大语言模型，可点每层）；GD `ch02-core-loop.html`（秒级 / 分钟级 / 天周级三层循环）、`ch22-games-and-reality.html`（魔圈：圈内规则、圈外现实）。
- **画法**：同心圆或同心圆角矩形，层间留 ≥18px 让引线穿过；**每层的名字和例子都在图外右侧**，引线连到该层的边；最内层可放一个小图标；点一层 = 这层描边加粗 + 填强调色淡底，其余变淡，信息框写"它比外层多了什么"。
- **常见错误**：把层名写在圆环里、压在边框上（GD 旧版最常见的毛病）；层太多（>4）挤成一团；读者分不清"包含"还是"先后"——包含用嵌套，先后用流程。

### 3 流程 / 管道
- **讲什么**：一件东西经过几道工序变成另一件东西；有方向、不回头。
- **三课例子**：GD `ch03-player-motivation.html`（约定奖励→被感知为控制→自主感下降→兴趣更低）、`ch13-accessibility.html`（一个事件同时走画面、声音、震动三条通道）、`ch28-paper-prototype.html`（纸面原型六步）、`ch29-build-web-game.html`（HTML→DOM→渲染树）；AI `ch11-backpropagation.html`（计算图从左往右）。
- **画法**：从左到右（窄屏改从上到下）；每道工序一个框，框之间的箭头上写"发生了什么"（动词）；进出的东西画成小物件（纸条、方块），让读者看见"东西在流动"。分叉用 Y 形，汇合用 ⋀。
- **常见错误**：箭头上不写字，读者不知道每步做了什么；把循环画成流程（最后一步回到起点就该用模板 1）；超过 6 步不拆。

### 4 坐标 / 象限
- **讲什么**：两个独立维度决定位置；或四类东西由两条轴切出。
- **三课例子**：GD `ch06-flow.html`（技能 × 挑战的心流通道，左上焦虑、右下无聊）、`ch03-player-motivation.html`（Bartle 四象限）、`ch10-ui-onboarding.html`（UI 四象限）、`ch27-playtesting.html`（研究方法：自述↔行为 × 定性↔定量）；AI `ch05-supervised-unsupervised.html`（多大 × 多重的地板坐标图）。
- **画法**：两条轴两端都写白话（"太简单 ↔ 太难"），不只写变量名；象限名放在象限内角、离轴 ≥8px，各配一个代表例子的小图；要读者判断位置时做成 G4 拖拽（"把这个游戏拖到你觉得的位置"）。
- **常见错误**：轴只有名字没有方向；象限名压在轴线上；四个象限用四种颜色却没有文字区分。

### 5 对比两栏
- **讲什么**：同一件事的两种做法、改前改后、正例反例。
- **三课例子**：GD `ch07-game-feel.html`（无反馈方块 vs 有反馈方块）、`ch26-prototype-iterate.html`（一次定稿 vs 每轮反馈）、`ch29-build-web-game.html`（等待输入型 vs 游戏循环）；AI `ch15-tokens-embeddings.html`（独热向量 vs 嵌入）。
- **画法**：两栏同尺寸、同构图、同起点，**只让要比的那一处不同**；左右各一个文字签 ✓ / ✗ 或"之前 / 之后"；差异处用强调色圈出。要看细微差别时用 E2 拖线对比。
- **常见错误**：两栏画法不同，读者分不清差异来自概念还是画法；差异点没圈出；用颜色当唯一区分。

### 6 时间轴 / 节奏曲线
- **讲什么**：量随时间起伏（节奏、强度、记忆），或事件在时间上的先后。
- **三课例子**：GD `ch11-level-design.html`（关卡紧张度起伏，休息点在波谷）、`ch07-game-feel.html`（一次打击的反馈时间线：确认、顿帧、挤压、余震，可点）、`ch24-case-mario.html`（1-1 教学时间线）、`ch14-randomness-probability.html`（输入随机→决策→输出随机）；AI `ch14-compute-gpu.html`（年份带）。
- **画法**：横轴是时间，刻度写白话单位（"第 1 秒""第 3 关"）；关键时刻打竖虚线 + 图外标签；起伏曲线的波峰波谷各配一个场景小图；可点的时刻做成热区。发明故事的年份时间线用 T5，不用这里。
- **常见错误**：曲线标签贴着线写，和线重叠；刻度太密；把示意曲线画得像真实数据却不标"示意"。

### 7 树 / 分类
- **讲什么**：一分为几、再分为几；决策分叉；技能 / 分支结构。
- **三课例子**：GD `ch08-meaningful-choices.html`（决策树，选项标收益 / 风险 / 代价）、`ch09-narrative.html`（分支树不断分叉）、`ch14-randomness-probability.html`（点数之争的决策树）、`ch16-progression.html`（技能树：线性、分叉、汇合）；DS `ch04-unfinished-game.html`（所有可能的时间线）。
- **画法**：根在上或左；同一层节点对齐；层数 ≤4，每层 ≤5 个，超出折叠成"……还有 3 种"；叶子节点配小图或例子；概率 / 数值写在边上，离线 ≥4px。决策树可做成"点一枝看结果"。
- **常见错误**：分类标准混用（同一层既按颜色又按大小分）；树太宽，手机上横滚看不全（要么竖排、要么拆两张）。

### 8 维恩 / 重叠
- **讲什么**：两三类东西有交集——"既是 A 又是 B"的那一块才是重点。
- **三课例子**：三课用得少。最接近的是 AI `ch10-perceptron.html`（两张各剪一刀的半透明纸叠起来，只认两张都盖到的地方）、GD `ch01-what-is-a-game.html`（家族相似：交叠的相似性网络）。新课遇到"交集"类概念时优先考虑它。
- **画法**：最多 3 个圈；圈用半透明淡底 + 墨色描边，交集区单独填强调色；每个区域放一个具体例子（不是区域名），区域名放圈外用引线；点一个区域高亮它并说明"为什么落在这里"。
- **常见错误**：圈名写在交集里；4 个以上的圈（看不懂，改用表格）；例子落在边界线上，看不出属于哪块。

### 9 天平 / 拉锯
- **讲什么**：两股力量此消彼长、要找平衡点；权衡、取舍、相克。
- **三课例子**：AI `ch10-perceptron.html`（天平：权重砝码 vs 门槛砝码）、`ch06-reinforcement-learning.html`（跷跷板上的平均）、`ch20-scaling-laws.html`（算力定了，参数和数据此消彼长）；GD `ch08-meaningful-choices.html`（重剑 vs 弓的权衡）、`ch15-balance-economy.html`（三角相克，圆圈大小随参数变）；DS `ch09-arrows.html`（挑人之后身高和球技像跷跷板）。
- **画法**：支点和两端都画成实物（砝码、小人、跷跷板），两端各写"是什么在往这边压"；倾斜角度跟着读者的参数变（做成 G2 活图最好）；平衡点用强调色标。
- **常见错误**：只画静态天平，读者感受不到"此消彼长"；两端的量没有单位或例子。

### 10 网络 / 关系
- **讲什么**：多个东西两两相连，关系本身就是重点——因果图、偏差来源、概念关系、社会网络。
- **三课例子**：DS `ch09-arrows.html`（因果图搭建台，六个变量可拖、可连箭头）、`ch02-filtered-shadows.html`（选择偏差关系图）；GD `ch27-playtesting.html`（四种偏差流向"你"）、`ch16-progression.html`（进度系统类型以"进度"为中心）、`ch06-flow.html`（三个条件一起指向心流）；全课的 `map.html` 概念关系图。
- **画法**：节点 ≤8（多了做成 `modules.md` 的概念关系图）；**边的类型靠线型 + 文字区分**（实线 = 导致，虚线 = 相关，箭头方向 = 谁影响谁），不只靠颜色；中心节点最大；点一个节点只亮它的邻居。
- **常见错误**：线交叉成一团（先手排位置，不用力导向自动布局）；边没有标签，读者不知道线代表什么。

### 11 光谱轴（补充）
- **讲什么**：一个维度上从一端到另一端的连续变化，各种实例按程度排开。
- **三课例子**：GD `ch01-what-is-a-game.html`（嬉戏 paidia → 竞技 ludus）、`ch18-multiplayer.html`（纯合作 → 纯竞争）、`ch21-ethics-monetization.html`（卖选择 → 卖痛苦）、`ch22-games-and-reality.html`（游戏 → 现实）。
- **画法**：一条粗轴，两端写白话极端（"毫无规则 / 规则严密"）；实例画成小图挂在轴上，名字在下方；可做成 G4 拖拽"你觉得它在哪"。
- **常见错误**：实例只写名字没有小图；中间一段没有例子，读者以为只有两极。

### 12 层叠 / 堆积（补充）
- **讲什么**：一个整体由几层叠成，或几部分加起来等于总量。
- **三课例子**：AI `ch04-overfitting-generalization.html`（期末误差拆成噪声 / 偏差 / 方差三层）、`ch12-cnn-imagenet.html`（四级台阶：短边→形状→部件→物体）；GD `ch05-emergence-systems.html`（简单规则→相互作用→整体）、`ch16-progression.html`（从飘字到升级弹窗的反馈层次）。
- **画法**：底层画在下面（地基感）；每层 = 名字 + 例子，放在层的右侧图外；能点一层看这一层贡献了多少；堆积柱用 `--q*` 编码和正文一致。
- **常见错误**：层名写在层里被色块吃掉；层的顺序和"谁依赖谁"不一致。

## 四、HTML 结构示意

kit 的写法（以模板 2 为例；其余模板同样是声明式或 `VL.diagram.<名>()`）：声明式或 JS 调用，SVG、引线、信息行都由 `diagrams.js` 生成，不手写。

```html
<figure class="vl-fig" id="c01-nest" data-diagram="nested">
  <script type="application/json">{"layers":[
    {"name":"大语言模型","eg":"会接着写下一个词","info":"<b>大语言模型</b>：比外层多了……"},
    {"name":"深度学习","eg":"很多层的神经网络"},
    {"name":"机器学习","eg":"从例子里自己找规则"},
    {"name":"人工智能","eg":"让机器做聪明的事"}]}</script>
  <figcaption>四个词不是并列的四样东西，而是一层套一层：越往里越具体。</figcaption>
</figure>
```
等价的 JS 写法和返回值见 `kit/README.md` 第九节"两种写法"。

生成的结构里，框 `.vl-dg-box`、线 `.vl-dg-ln` 可加皮肤滤镜（手绘抖动），文字 `.vl-dg-t1`（名字）/ `.vl-dg-t2`（例子）/ `.vl-dg-t3`（小字）、引线 `.vl-dg-lead` 不加；皮肤可用的全部类名见 `kit/README.md` 第九节"皮肤可用的类"。手写 SVG 图（kit 的 12 种模板画不了的图）照同样分层：形状组加滤镜，文字组在滤镜外，可点的块 `g[tabindex=0][role=button]`。

## 五、什么时候不画图解

| 情况 | 改用 |
|---|---|
| 这段话没有结构，只有一个场景或一件事 | 场景插画、真实照片 |
| 要讲"改一个数会怎样" | G2 活图（图解只能画一种状态） |
| 只有两三个并列名词，没有关系 | K2 并列卡阵，或一句话说完 |
| 图解只是把正文的句子装进框里、加了箭头 | 删掉——删掉后读者理解不变差，它就不该在 |
| 上一个视觉也是静态图解 | 中间先隔一个插画、例子或互动（`SKILL.md` 节奏规则 3） |
| 关系太多（>8 个节点、>3 个圈、>4 层） | 拆成两张，或换成表格 T8 / 概念关系图模块 |
| 讲历史、人物 | 真实图片、带图时间线 T5 |
| 已经有一张图讲过同一个结构 | 回指"看图 3"，不重画；同一张图全课只用一次 |
