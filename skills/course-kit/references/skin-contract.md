# 皮肤契约

用途：一套皮肤必须交付什么（变量、组件外观、插画工具、专属动效）、怎么验收入库，以及现有皮肤一览。选皮肤时读本文件末尾的一览和 `skins/<名>/README.md`；视觉底线在 `SKILL.md` 第二节。文件结构以 `kit/README.md` 为准。

**皮肤 = 一份样式 + 一套插画画法 + 少量装饰和氛围动效。** 组件的结构、交互、导航、测验、轮播脚本都和皮肤无关，直接复用。皮肤开课时定（插画按皮肤画法画）；读者只能切换配色（亮 / 护眼；暗色有变量，未完整验收）。

## 一、必须定义的 CSS 变量

写在 `:root`；按篇用 `body[data-part="n"]` 覆盖主色（vl.js 按篇序号写 1、2、3……，notebook 用 `--p{n}a/b/p/l` 五套）；配色用 `html[data-scheme="dark"]`、`html[data-scheme="sepia"]` 覆盖。vl.js 另给皮肤三个钩子：`body[data-pat]`（章号 % 4，换纸纹）、`--vl-dh`（同篇色相微移 −18…+18）、`--vl-chnum`（两位章号，做角标）。组件只引用变量，不写死颜色。

| 组 | 变量 | 硬要求 |
|---|---|---|
| 文字 | `--ink` 正文、`--ink2` 次要、`--muted` 注释 | 三者对 `--panel` 都 ≥4.5:1（`--muted` 也是；下限参考 DS `#4d566c`） |
| 底与面 | `--page` 页面底、`--panel` 正文面、`--edge` 实体件的边、`--sunk` 控件底 / 凹槽 | 长文直接排在 `--panel` 上，不另浮卡片；底面要有细微质感（纸纹、纤维），不是平涂 |
| 图板 | `--plate` 图与插画的底、`--plate-ink` 图中文字 | 暗色和护眼配色下 `.vl-fig`、`.vl-cc-fig`、单独的 `.vl-illus` 保持浅底，插画内部颜色不用随配色改；`--plate-ink` 对 `--plate` ≥4.5:1 |
| 主色 | `--accent`、`--accent2`、`--deep` | 浅主色只做底色；写字用 `--deep`（≥4.5:1）；选中态按钮的字对底 ≥4.5:1（反例：DS 视图切换白字压 accent2 约 1.6:1） |
| 强调 | `--hl` 荧光底、`--focus` 焦点描边 | `--focus` 在 `--page` 和 `--panel` 上都 ≥3:1 |
| 状态 | `--ok` `--okbg` `--no` `--nobg` `--warnbg` | 状态都另配 ✓ ✗ 虚线等图形，不只靠颜色 |
| 量的编码 | `--q1` … `--q6` | 有数学的课必须；在 `--panel` 和 `--plate` 上都 ≥3:1；全课固定，换配色时逐个校对比度 |
| 字体 | `--font-body` 正文、`--font-label` 小标题 / 按钮 / 标签、`--font-hand` 手写体、`--font-display` 大标题、`--font-mono` 数字 / 代码 | 见下方字体规则 |
| 形状 | `--stroke` 描边宽、`--radius`、`--radius-alt`（非对称圆角用）、`--shadow-obj` 实体件投影、`--shadow-soft` | 只有"东西"用 `--shadow-obj`，投影同向；粗描边只给互动台和概念图解 |
| 动效 | `--ease`、`--dur-fb`（≤300ms）、`--steps`（像素皮肤用） | 见 `interaction.md` 第四节 |
| 图解 | `--dg-c1…c6` 节点底色、`--dg-ink` `--dg-ink2` 线与字、`--dg-hi` 选中、`--dg-filter` 手绘滤镜（数据图不用） | 图解在图板上，三套配色都不变；类名见 `kit/README.md`"概念图解" |
| 插画 | `--il-filter`；配色写在 `skin.js` 的 `VL_SKIN.palette` | 同上 |

**字体规则**
- `--font-display`（书法、粉笔、像素等装饰体）只用于 h1 和大章号。
- `--font-hand` 只在**验证过清晰**后用于小标题、图中文字、按钮：在 13px 和 16px 下截图读一遍；字母数字另配清晰字体，用 `unicode-range` 只管 U+0030-0039、U+0041-005A、U+0061-007A（GD 的做法：马善政管汉字、Patrick Hand 管字母数字，解决了"VR5"被看成"9R5"）。
- 正文用清晰字体（三课都是霞鹜文楷，17.5–18px / 1.85）。
- 字体本地 woff2，中文字体太大时按全课用字裁剪子集（如 fonttools 的 `pyftsubset`，新章要重跑）；网络字体用 JS 异步插入 `<link>`，不在 CSS 里 `@import`（反例：GD `style.css` 第 1–3 行）；系统字体兜底。
- 换字体前在小页面里对比，再全课重跑 `qa.mjs`（字宽变了，间距跟着变）。

**三套配色**

| 配色 | 改什么 | 不改什么 |
|---|---|---|
| 亮（默认） | — | — |
| 暗 | `--page` `--panel` 变深，`--ink*` 变浅，`--accent*` 提亮一档，`--shadow-*` 变成更深的影或亮边 | `--plate` 保持浅底（图和插画是"一张东西"）；插画、照片不反色 |
| 护眼 | `--page` `--panel` 偏暖米黄，`--ink` 偏暖深棕，降低主色饱和度 | 同上 |

顶栏"显示"里切换，存档键 `vl-scheme`（不带课程前缀，跨课、两种语言共用）；`kit/vl-head.js` 在首屏前写 `html[data-scheme]`。首次访问默认亮色（kit 现在不跟随 `prefers-color-scheme`）。三套配色都要过对比度检查。

## 二、必须画出样子的组件

同一个功能，每套皮肤一个样子。`skins/<名>/gallery.html` 把下面每一项都摆出来，作为验收页（`skins/notebook/gallery.html` 已摆好 kit/vl.js 现有的全部组件，做新皮肤时复制它、只换皮肤路径；网址加 `?scheme=dark|sepia` 截三套配色）。互动组件、可选模块、12 种图解的演示分别在 `kit/demo-interact.html`、`kit/modules/demo-modules.html`、`kit/demo-diagrams.html`，做新皮肤时一并对照。

| 类 | 组件（编号见 `components.md`） |
|---|---|
| 外壳 | N1 顶栏（含配色、动效三档开关）、N2 章首（含插画位）、N3 节号与小标题、N4 目录浮钮 + 进度条、N5 翻页 |
| 实体件（最重） | G1 互动台 + 控件族（按钮主 / 次 / 禁用 + 按下态，chip 四态 `.on/.right/.wrong/.miss`，滑块，分段切换）、概念图解外框 |
| 实体件（中） | M3 试试看（未完成 / 完成两态）、T4 照片框 `.vl-fig.photo`、K9 文档道具至少 3 种 `data-kind`、K1 概念卡（含图位） |
| 轻块 | K3 原理框、K5 立场卡、K6 收束块、K8 旁注、K10 发明故事框和 P4 支线的摘要、E1 轮播页签 + 反例标记 |
| 图 | T3 图中字体与线条（概念图可抖动、数据图笔直）、数据图配色、T7 图例形状、`--q*` 编码示例 |
| 练习 | P1 测验（一题、三态圆点、全对徽章）、P3 笔记框 |
| 目录页 | 一种学习地图画法（棋盘、塔、路线图、小镇……）；起点是 `starter/index.html` 的按篇章节卡片 |
| 激励外观（如皮肤打算支持） | `modules.md` 第一节外观表的一列 |
| 焦点态 | 每种可交互件的 `:focus-visible` |

层级要分得出来：互动台和概念图解最重（粗框、垫层、投影）；概念卡、照片、文档道具是"东西"，有实体但轻一档；原理框、立场卡、支线是轻块（竖线、小签、无投影）；长文没有框。

## 三、插画画法说明

插画装载器和火柴人绘制工具在 `kit/illus.js`（`VL.illus.kit`），接口与皮肤无关；皮肤只给配色（`skin.js` 的 `VL_SKIN.palette`）和线条滤镜（`--il-filter`）。画法完全不同的皮肤（剪纸、像素、离线渲染）另交一个绘制工具，**接口照下表**（参数以 `kit/README.md`"插画位"为准）：

| 函数 | 要求 |
|---|---|
| `kit.person(x, y, opts)` | 人物画法全课统一；靠发型、帽子、配饰、服装区分（`opts.hat/hair/glasses/beard/tie/cape/shirt`），同一张图按出场顺序自动换装（`outfit:false` 关）；`opts.legs:'sit'` 自动配椅子（`chair:false` 关）；`opts.arms:'hold'` 时用 `kit.holding(x, y, opts, 物件)` 把物件画在两手之间（`kit.hands()` 取两手坐标）；`opts.look:-1` 朝左，手臂腿自动镜像，文字放文字层不翻；脚底 `kit.feetY()` 落在 `ground` 上 |
| `kit.ground(y)` | 地面线或地面块，人物和物件都站在它上面 |
| `kit.item(name, x, y)` | 常用物件库（kit 现有 book box cup phone die star coin），放在桌上用 `item`，拿在手里用 `holding` |
| `kit.bubble(x, y, w, h, [尾尖x, 尾尖y])` + `kit.T(x, y, 字号, 文字, anchor)` | 气泡尾尖对准说话人；字放在 `VL.illus.add` 的第 4 个参数（文字层，在滤镜组外）；字短（≤12 字）；不压人物 |
| `kit.arrow(x1, y1, x2, y2)` | 尖端正好落在终点 |
| 椅子 / 桌子 | 防悬空：kit 的坐姿自带椅子，`arms:'desk'` 是伏案姿势；单独的 `chair / desk` 物件 kit 里暂无 |

- 画布默认 viewBox 200×140；人物缩放 ≥0.9，别画太小。
- 文字放在滤镜组外；滤镜写 `in="SourceGraphic"`。
- 规则写进函数比事后逐张改省事（GD 经验：坐姿自动配椅子、脸朝左手臂自动镜像）。
- 交付时附：一页人物样张（6 个不同人物站、坐、拿东西、指东西、说话）+ 物件样张；`tools/illus-overlap.mjs` 通过；用 `tools/shot.mjs` 逐张截单个插画人眼看过。
- **怎么接进 kit**：kit/illus.js 暂时没有正式的换画法钩子。paper、pixel、fieldbook 的做法相同：`skin.js` 在 `window.VL` 上给 `illus` 装一个 setter，kit 赋值时把自己的绘制工具并进同一个 kit 对象，所以 `skin.js` 必须在 `kit/illus.js` 之前加载（starter 模板就是这个顺序）。新皮肤照抄这三套之一。
- 一页只用一套画法：皮肤的绘制工具没做完，就别开这套皮肤的章（反例：AI W4 章插画仍用像素库）。
- 三课踩过的坑见 `visuals.md` 第三节。

## 四、专属动效

皮肤可以带氛围动效和反馈动效的"手感"，但都要受档位控制（`vl-fx-full / -lite / -off`，见 `interaction.md`）：

| 必须 | 说明 |
|---|---|
| off 档完全静止 | 环境动画清空，开场、过场直接跳过 |
| lite 档 | 环境动画静止，开场缩短 |
| 出视口暂停 | 题头环境动画离开视口就停（正例：DS `ambient`） |
| 开场 / 过场可点跳过 | 每次会话每章最多播一次 |
| 只在正文以外 | 正文区不放常驻动画 |
| 截图可冻结 | 支持 `?freeze=秒` |

## 五、验收流程：样稿 → 用户验收 → 入库

1. **选方向**：和用户聊清楚想要的感觉，找 2–4 个参考方向说明理由，用户挑一种（用户否定过的方向不再推：科幻全息、矢量线框、街机像素、水墨、工程图纸、极简线路图、纪念碑谷粉彩、1-bit 版画、小镇积木、毛线布艺）。
2. **做样稿**：
   - 变量（三套配色）、`skin.css`、`skin.js`（`VL_SKIN`：网络字体、滤镜、插画配色）、画法不同时另交绘制工具（第三节）、字体子集；
   - `gallery.html`：第二节清单全部摆出；
   - 一章真实内容的样板章（不是假文），用到至少一个招牌互动、一张概念图解、一组例子轮播、一张真实图片。
3. **自检**：
   - `node tools/qa.mjs <绝对路径>` 无报错、无横向溢出；
   - `node tools/shot.mjs` 截 420 与 1100 宽 × 三套配色的整页，再截每张插画单元素放大看；
   - 对比度用工具实测（不估算）：正文、次要字、图注、图中字、选中态按钮、`--q*`；
   - 减少动态下无氛围动画；打印样式全展开、无深色底；
   - 双击 `file://` 打开正常（反例：AI W8 样稿 `mask-image` 引本地图在 file:// 下整块消失，改用 `-webkit-mask-box-image`）。
4. **给用户验收**：发截图 + 一句话说明 + 待定问题清单（"套印错位会不会太花？""16px 点阵字能否接受？"这类具体问题）。用户提的意见改在样稿上再给看，不直接铺开。
5. **入库**：通过后放进 `skins/<名>/`，`README.md` 写：适合什么课 / 读者、参数摘要（配色、字体、底面、描边、插画画法、篇章变化）、专属动效、已知问题、用户验收日期和原话要点。之后用户对这套皮肤的反馈改在这份 README 的原条目上。
