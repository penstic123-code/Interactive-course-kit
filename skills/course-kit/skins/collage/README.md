# 皮肤 collage · 贴纸拼贴

用途：本皮肤的风格、变量、插画画法和适用场合。

**一句话**：一张有纤维的暖白手工纸，长文直接印在纸上；照片、名画、插画、互动台、概念卡都是剪下来贴上去的纸，靠错位的彩纸垫层和同向浅投影分层，不描黑边。颜色取马蒂斯剪纸的几种纯色。

## 文件

| 文件 | 内容 |
|---|---|
| `skin.css` | 变量（三套配色 + 五篇主色）+ 组件外观 + `.cl-sticker` 小贴纸 |
| `skin.js` | `window.VL_SKIN`：网络字体、贴纸滤镜 `#cl-stk`（白边 + 浅投影）、插画配色、**贴纸绘制工具**（经 kit 的换画法钩子 `VL_SKIN.illus` 装进 `VL.illus.kit`，`skin.js` 须在 `kit/illus.js` 之前加载） |
| `interact.css` `modules.css` `diagrams.css` | 互动组件、可选模块、后七种图解的外观（与 notebook 相同） |
| `fonts/` | Patrick Hand（字母数字手写体）+ OFL 授权，本地，离线可用 |
| `gallery.html` | 验收页 |

## 谁是什么

| 印在纸上（无框） | 贴上去的纸 |
|---|---|
| 正文、学习目标、原理框（左边一条剪下的纯色纸条 + 小签）、要点 | **最重**：互动台（浅色卡纸 + 错位 12px 篇色垫层 + 顶边 8px 纯色条）。**中**：概念卡（白卡 + 错位 10px 彩纸 + 胶带）、编号图、照片和名画（白边贴纸：9px 白边、14px 圆角、歪 −0.8°）、例子轮播（彩纸小页签 + 白纸）。**轻**：收起块（便条纸）、试试看（黄便签 + 胶带）、笔记框（横线信纸） |

起名处是一条浅色纸条垫在字下（只给概念第一次被命名处），着重用着重号。节号是剪下的圆纸片，章首徽记是一块纯色纸。

## 插画画法（`skin.js` 的绘制工具，接口照 kit）

- 无描边平涂剪纸人：头、发、上衣、手臂、裤腿、鞋各是一块色纸；脸两点一笔。每个人、每件物件外包 `#cl-stk`，就是一张白边贴纸，和照片贴纸同一种质感。
- 几何与 kit 默认一致，`hands()` `feetY()` 直接沿用；站姿脚底落在 `ground()`（126）上，`legs:"sit"` 自带木凳（`chair:false` 关）。
- 换装：同一张图里依次 短发 → 鸭舌帽 → 长发 → 毛线帽 → 盘发，上衣色、肤色同时轮换；`outfit:false` 关掉。另有 `tie cape beard glasses`、`hat: tophat crown wizard`。
- 物件：kit 的 book box cup phone die star coin；`k.sticker(形状)` 把任意形状包成贴纸。
- 地面是一条淡铅笔线；气泡是白色贴纸。文字放 extra 层，不进滤镜。
- 图解（diagrams.js）不加滤镜（`--dg-filter:none`），数据图笔直。
- 一页只用一套画法：照片、名画、插画都做成白边贴纸，不让卡通和真实质感直接混排。

## 专属动效

无氛围动画；轻量档去掉悬停歪斜。

## 何时适合用

- 适合：要放大量名画、历史照片、实物照片的入门课（教育、艺术史、心理学、生物）；成人和高中生。
- 不太适合：大量精确数据图的课；需要强烈游戏感的课。

## 验收

- 2026-10-26 用户同意入库。来由：用户要"艺术史风格 + 照片和名画"，又否决"卡通和真实质感混在一起"，办法是照片、名画、插画统一做成白边贴纸；参考了"贴纸风科普"截图（零件贴纸 + 引线标签拆解）。
