# 皮肤 fieldbook · 田野手账

用途：本皮肤的风格、变量、插画画法和适用场合。来源：人类学课的“调查笔记”样式（css/style.css 末层）和插图库（js/illus.js），去掉了课程专属的向导角色、贴纸和书签。

**一句话**：牛皮纸桌面上摊开一页方格活页纸，左边装订孔和红色页边线，右边彩色篇章索引签；研究者自己写的东西直接写在纸上（彩铅竖线 + 荧光笔小标题），贴进本子的东西（照片、插画、图解、互动台、索引卡）是同一质感的纸片，用胶带固定。

## 谁是什么

| 铅笔层：直接写在纸上（无底无框无影） | 纸片层：贴进来的东西（1px 纸边 + 浅投影 + 3px 圆角 + 哑光纹） |
|---|---|
| 学习目标、误区、要点、一句话总结：一道彩铅竖线 + 荧光笔小标题；试试看：一个歪一点的待办方框，做完打勾；时间线：虚线 + 圆点 | **最重**：互动台（方格稿纸，顶边一道篇色，`--shadow-obj`）、编号图和图解（白纸 + 胶带）。**中**：概念卡（索引卡，红色抬头线 + 胶带歪贴的图位）、照片（白边相纸、老照片色调、蓝绿胶带、歪 0.8°）、测验卡、例子轮播（活页分隔页签 + 一张纸）。**轻**：原理框（牛皮纸档案页 + 档案签，平放无投影）、收起块（对折便条）、先猜后揭晓（黄便利贴） |

控件是纸做的：暖纸色底、1.5px 墨线边、4px 圆角，不用冷蓝灰。文档道具除 kit 现有的 `file news diary letter lab`，另有 `ticket`（票根）、`clipping`（剪报）、`copy`（影印件）。

## 插画画法（`skin.js` 里的绘制工具，接口照 kit）

- 墨线 + 淡彩：人物有衣服色块、肤色手、短脖子；**眼睛两个点、嘴一条线**（`o / shout / wide` 是小圆口，`sad` 微弯，`closed` 两条短线）；脸放在 `.norough` 组，不抖。
- 坐标照 kit：`person(x, y)` 的 y 是头部中心；站姿脚底 `y+64·s`、坐姿 `y+63·s`，正好落在 `ground()`（126）上；`legs:"sit"` 自带木凳（`chair:false` 关）。
- 换装：同一张图依次 无 → 鸭舌帽 → 长发 → 渔夫帽 → 草帽，上衣色同时轮换。kit 的帽名映射：`beanie`→渔夫帽，`tophat / crown / wizard`→遮阳盔。另有 `hair: short long bun bob curly bald`、`hat: bucket straw cap pith scarf`、`coat`、`bottom: skirt sarong`、`top`、`skin`。
- `arms`：kit 的全部姿势（stand none up cover point hold wave chin throw club desk）；`holding()` 的物件夹在两手之间。
- 物件：kit 的 book box cup phone die star coin，另有 notebook letters basket bag shell trowel mic；场景件 `stool table house tree sun`，以及 `P / Ci / E / B / W`（路径、圆、椭圆、矩形、淡彩块）。都在 `VL.illus.kit` 上。
- **彩铅化**：Rough.js 把 `.vl-il-rough` 组里的描边重画成铅笔线，大块色面改成彩铅排线 + 淡水彩底；插画进入视口才处理（隐藏的轮播页、收起的分节量不出尺寸）；压着文字的色面只铺淡彩不排线。没有 rough.js 时退回 `#vl-fb-wobble` 微抖。页面脚本后画的插画调 `VL_SKIN.roughen(根节点)`。只描边不排线的图加 `data-nohatch`。
- 图解（diagrams.js）不彩铅化，只用 `--dg-filter` 微抖；数据图笔直。
- 一页只用一套画法：这套皮肤的章，互动和插画也要是手绘纸片风，不放写实材质。

## 专属动效

无氛围动画。只有弹层轻移入、试试看打勾弹一下、测验徽章盖章；`vl-fx-off` 全停。

## 何时适合用

- 适合：人文、社科、田野调查、历史、考古、语言、民俗；成人和高中生；照片、文献、票据多的课。
- 不太适合：大量精确数据图的课（可以用，但整体气质偏文）；低龄、游戏化的课。

## 已知问题

- 暗色只给了变量，未逐组件精调（用户暂缓暗色）。
- Rough.js 每张插画首次进入视口时重画，插画很多的页面滚动时首帧会略卡。
- 站姿 / 坐姿身高与 kit 火柴人一致，但宽一些；kit 坐标写成的旧插画搬过来时，物件可能要挪几个像素。
- 用户尚未就“抽成皮肤后的样子”验收（来源课程的风格已于 2026-10-22 验收：“全课统一笔记本风格、加强质感与和谐感”）。
