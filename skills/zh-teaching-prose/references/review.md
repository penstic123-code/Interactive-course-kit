# 审稿清单：逐句查 AI 腔和文风问题

用法：一段一段读，每段先读出声（或在脑子里默读一遍），再对照下面的类型。只报问题和证据，不写客套。

## 一、句子层面（最常见，逐句查）

| 类型 | 怎么认出来 | 改法 |
|---|---|---|
| 对仗模板 | 连续两三句"前半句捧、后半句摔"（做到之前/做到之后；能赢冠军/连衣服都不认识） | 只留一处对比，其余改成顺叙；或把对比拆进不同段 |
| 贴标签 | "人们给它起了个名字，叫 X""……的，叫 Y"，而且每段都是"例子 → 定义" | 名字顺着叙述带出来；换一段的推进方式 |
| 段首固定短句 | 段落第一句是一个自成一句的短句，后面才是正文。四种：断言（"这不是我编的。""小比特当然算。""第 3 局最憋屈。"）、指路（"再看票数。""回到小屋。"）、短反问（"计算器呢？""知识从哪来？"）、预告（"先拿一个游戏角色来试。""这还没算上前文。"） | 删掉，直接从事实写起；需要过渡的并进下一句（"何况每张纸条前面还有一段对话。"）。改完专门再扫一遍每段第一句 |
| 硬切 | 新段落突然换了对象，读者不知道为什么现在讲这个 | 加一句过渡，接住上一段留下的东西 |
| 考试式收尾 | 段尾一句概括全段的总结、升华 | 删掉，或改成一个由下一段马上回答的问题 |
| 翻译腔 | 英文概念直译当日常词（光谱、维度、层面）；"在她写……的书《X》里"这类长定语 | 换成中文里人会说的话；长定语拆成两句 |
| 缺主语 | 读完不知道谁做的（"所以这里把中文换成了……"） | 补出主语；没有施事者就用"被"字句 |
| 连接词错 | 不是因果却用"所以"；不是转折却用"可是" | 换成表达真实关系的词，常见的是"而" |
| 虚词赘余 | 其实、也、就、确实、只是、了 | 删掉意思不变就删 |
| 防御性写作 | 怕说错而加的"大致、未必、当然、某种程度上"，括号里的免责 | 删；真不确定就在那件事上说一次 |
| 套话 | 不是……而是、值得注意的是、换句话说、本质上、总的来说、这正是、真正的 | 删掉套话，直接说内容 |
| 破折号 | "——"用来插入解释、补充、制造停顿，一段里不止一处 | 改成逗号、句号或拆成两句 |
| 递进/分点套话 | "不仅……更……""不只是……还是……"；正文里的"首先、其次、最后" | 按事情本身的顺序讲，换成表达真实关系的连接词 |
| 大词渲染 | 桂冠、圣杯、命运的齿轮、神挡杀神、那才叫真正的 | 换成平实的说法 |
| 指代不清 | "它、这、那"跨句后读者要回头找 | 把名词再写一遍 |
| 名词化 | "进行……的更新""起到……的作用" | 改成动词 |
| 点名读者 | 一段里多次"你""我们"，或作者"我"在正文里突然出现 | 让事情本身当主语 |

## 二、段落和结构层面

- 开场有没有从读者熟悉的经验交代前因后果，还是空投进一个场景？
- 遮住小标题从头读，能不能顺着读下去，知道每段为什么出现？像提纲就要重写。
- 事情是不是按时间先后讲？有没有先讲后来的事、再倒回去？
- 读者不需要的数字、年份、人名有没有删干净？
- 故事、历史、游戏是不是比概念本身还多？
- 小标题只看它能不能说出这节讲什么？第一次起名的概念在不在标题里？
- 角色对话有没有替作者讲课、念定义、工整一问一答？

## 三、汇报格式

逐条：`位置（第几节 + 原句前 15 个字）｜类型｜原句｜改写`。不确定的标"疑似"。最后列出最常出现的 3 类毛病，方便作者一次性在全文里搜同类。
