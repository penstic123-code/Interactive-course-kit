# 审稿清单：按三层逐句查

用法：一段一段读，每段先读出声（或在脑子里默读一遍），先查原则，再查 AI 腔信号，最后查偏好。三层的定义见 SKILL.md "三层规则"，这里只列怎么查，不重复规则内容。只报问题和证据，不写客套。

## 一、原则（必守，先查）

句子和段落：

| 类型 | 怎么认出来 | 改法 |
|---|---|---|
| 短句罗列 | 一句一个事实，句与句之间没有连接，读起来像清单 | 让前句的结果成为后句的起点，用表达真实关系的连接词并句 |
| 硬切 | 新段落突然换了对象，读者不知道为什么现在讲这个 | 加一句过渡，接住上一段留下的东西 |
| 缺主语 | 读完不知道谁做的（"所以这里把中文换成了……"） | 补出主语；没有施事者就用"被"字句 |
| 连接词错 | 不是因果却用"所以"；不是转折却用"可是" | 换成表达真实关系的词，常见的是"而" |
| 指代不清 | "它、这、那"跨句后读者要回头找 | 把名词再写一遍 |
| 名词化、空壳词 | "进行……的更新""起到……的作用""问题、情况、层面" | 改成动词，写看得见的人和物 |
| 点名读者 | 一段里多次"你""我们"，或作者"我"在正文里突然出现 | 让事情本身当主语 |
| 知识的诅咒 | 缩写、行话、"显然"后面省了一步，零基础读者跟不上 | 补齐那一步，抽象说法前先放具体例子 |
| 句子过长 | 一口气读不完，或一句塞了两个主要意思 | 在意思转折处断开 |
| 虚词删过头 | 删光了"了、也、就"，句子发硬 | 恢复；只删删后意思和语气都不变的 |

结构：

- 开场有没有从读者熟悉的经验交代前因后果，还是空投进一个场景？（做法见 SKILL.md"叙事与结构"）
- 是不是先处境、后办法、最后才起名字？
- 遮住小标题从头读，能不能顺着读下去，知道每段为什么出现？像提纲就要重写。
- 讲历史或发明经过时，是不是按时间先后讲，有没有先讲后来的事、再倒回去？（讲概念和用法不用查这条。）
- 读者不需要的数字、年份、人名有没有删干净？
- 故事、历史、游戏是不是比概念本身还多？正文主语是概念还是故事角色，概念名有没有被故事里的叫法替代？（规则见 SKILL.md"概念为主"）
- 核心概念的例子够不够划出边界（数量见 content-rules 第一节第 7 条）？
- 小标题只看它能不能说出这节讲什么？第一次起名的概念在不在标题里？有没有口号、比喻式标题？
- 角色对话有没有替作者讲课、念定义、工整一问一答？
- 有没有元语言或对后文的预告？（见 SKILL.md "句子"末条）

## 二、AI 腔信号（成串必改，单个看上下文）

逐句扫下面的信号。判断方法：同一段里出现好几个，或同一种模式段段都有，就是成串，必须改；孤零零一个，看它在这里是不是真有用（比如"不是……而是……"确在纠正读者的误解、一处破折号确实带来必要的停顿），有用就留，并在报告里标"保留"。例外：标"必须避免"的（整段套路）单个出现也改。

| 类型 | 怎么认出来 | 改法 |
|---|---|---|
| 对仗模板 | 连续两三句"前半句捧、后半句摔"（做到之前/做到之后；写出来了/没写完） | 只留一处对比，其余改成顺叙；或把对比拆进不同段 |
| 贴标签 | "人们给它起了个名字，叫 X""……的，叫 Y"，而且每段都是"例子 → 定义" | 名字顺着叙述带出来；换一段的推进方式 |
| 段首固定短句 | 段落第一句是一个自成一句的短句，后面才是正文。四种：断言（"小比特当然算。"）、指路、短反问（"知识从哪来？"）、预告（"先拿一个游戏角色来试。"）；更多例子见 SKILL.md | 删掉，直接从事实写起；需要过渡的并进下一句。改完再扫一遍每段第一句 |
| 考试式收尾 | 段尾一句概括全段的总结、升华，或"要……，得……"式的教训句 | 删掉，或改成一个由下一段马上回答的问题 |
| 整段套路（必须避免） | 每段都是"断言 → 举例 → 金句"；分号并列的对仗；顿号三连加总结句；句与句之间没有转折，一句一个事实；单独成句的短结论；概念段、并列段同一骨架；逗号链长句 | 让上一句的结果成为下一句的起点，用真实的连接词；三连罗列改成一个完整场景；讲完就停 |
| 段段问句收尾 | 每段都以问题结尾，下一段再答 | 只留真正推动阅读的，其余换别的过渡 |
| 翻译腔 | 英文概念直译当日常词（光谱、维度、层面）；"在她写……的书《X》里"这类长定语 | 换成中文里人会说的话；长定语拆成两句 |
| 防御性写作 | 怕说错而加的"大致、未必、当然、某种程度上"，括号里的免责 | 删；真不确定就在那件事上说一次 |
| 套话 | 值得注意的是、有意思的是、换句话说、本质上、总的来说、这正是、真正的 | 删掉套话，直接说内容 |
| 造反差的"不是……而是……" | 立一个没人持有的靶子再推倒 | 直接说"是什么"；真在纠正读者的误解时可保留 |
| 破折号 | "——"用来插入解释、补充、制造停顿，密集出现 | 改成逗号、句号或拆成两句 |
| 递进/分点套话 | "不仅……更……""不只是……还是……"；叙述里的"首先、其次、最后" | 按事情本身的顺序讲，换成真实的连接词；操作步骤用编号列表不算 |
| 大词渲染 | 桂冠、圣杯、命运的齿轮、神挡杀神、那才叫真正的 | 换成平实的说法 |
| 硬升华、替读者安排体验 | 讲完概念硬转"其实生活里也……"；替读者安排体验（"想象一下你现在"）；悬念式指路 | 删掉，或换成有细节的真实例子 |

## 三、偏好（项目可调，最后查）

先看项目文档有没有另外规定，没有就按 SKILL.md "偏好"：

- 小标题有没有"X：Y"冒号格式？问句标题是否多于一个？是否超过 16 字？
- 一段里破折号是否多于一处？
- 强调标记是否超出 SKILL.md "偏好"里"强调标记"一条的规定？

偏好问题只报"建议"，不和原则、信号混在一起。

## 四、汇报格式

逐条：`位置（第几节 + 原句前 15 个字）｜层（原则/信号/偏好）｜类型｜原句｜改写`。不确定的标"疑似"，信号单个出现且判断保留的标"保留"。最后列出最常出现的 3 类毛病，方便作者一次性在全文里搜同类。

条数按场景：写作自审，全部报；读者审读（第三方读成品，见 content-rules 第八节）里的 AI 味，只报最明显的 5 处。
