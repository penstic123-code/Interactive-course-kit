# 【课程名】：项目规则与经验

用途：这门课专属的定位、数字标准、选用的皮肤与模块、写法和经验。通用规范在 course-kit 的 `references/content-rules.md`，画面与组件规矩在 course-kit skill，这里只写本课定下来、和默认值不同或需要记住的东西。同一条规则只写一处；用户的新反馈改在原条目上。

## 一、定位

| 项 | 本课 |
|---|---|
| 一句话 | 【这门课让读者学会什么】 |

| 学完能做到 | 【2–4 条可观察的事】 |
| 总用时 | 【N 章 × 约 M 分钟 ≈ X 小时】 |
| 贯穿线索 | 【可选：反复出现的案例 / 逐步完成的项目 / 背景故事（只在简报、题头图、陪伴角色里露面）/ 不设】 |
| 文风 | `zh-teaching-prose`；本课特有的写法写在第六节 |
| 英文版读者 | 【如：澳大利亚高中生，澳式拼写】；中文定稿后再翻译 |

## 六、本课的数字标准

默认值见 `content-rules.md` 一A；和默认不同的才写，写了就以这里为准。

| 项 | 本课 |
|---|---|
| 每章用时 | 【约 30 分钟】 |
| 分节数 | 【8–12】 |
| 核心概念 / 概念卡 | 【每章 1–3 个，各一张卡】 |
| 概念图 | 【≥3 张】 |
| 例子 | 【每概念 ≥3，含 1 个反例】 |
| 招牌 / 辅助互动 | 【1–2 / 0–2，大互动合计 ≤5】 |
| 练习 | 【4–6 题】 |
| 本课特有的写法 | 【如：不引原话、少用“你”、术语首次出现给英文】 |

## 七、工作流

| 项 | 本课 |
|---|---|
| 样板章 | 第【n】章，用户确认日期：【】 |
| 并行 agent 数 | 【一次一章 / 两三章并行，主控验收】 |
| 检查 | 每章交付前 `node <skill>/tools/check.mjs <课程绝对路径> chNN --fast` 修到 0，再跑完整版并看截图 |
| 读者审读 | 每章交付后派无上下文的审读 agent（`tools/readable.py`；输出标了正确答案，让它先闭卷自测再对答案） |
