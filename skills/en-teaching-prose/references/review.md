# Review checklist: three tiers, sentence by sentence

How to use it: go through the text one paragraph at a time. Read each paragraph aloud, or at least in your head. Check principles first, then AI-voice signals, then preferences. The tiers are defined in SKILL.md ("Three tiers of rules"); this file only says how to check, and does not repeat the rules. Report problems with evidence and leave out the pleasantries.

## 1. Principles (must hold; check first)

Sentences and paragraphs:

| Type | How to spot it | Fix |
|---|---|---|
| String of short sentences | One fact per sentence with nothing joining them, so the paragraph reads like a list | Let each sentence's result start the next, joined by connectives that state the real relationship |
| Hard cut | A new paragraph switches subject with no reason given | Add one linking clause that picks up what the last paragraph left |
| Wrong connective | "so" where there is no cause, "but" where there is no contrast | Use the word for the real relationship, often "and", "while" or nothing |
| Unclear reference | "it", "this" or "that" across sentences, so the reader has to look back | Repeat the noun |
| Needless passive | "The experiment was designed by Searle" when the agent is known | Put the agent in subject position |
| Nominalisation | "perform an analysis of", "the utilisation of", "make a decision" | Turn the noun back into a verb |
| Latinate abstraction / shell nouns | aspect, factor, dimension, mechanism, framework, dynamics; utilise, facilitate, demonstrate | Use concrete nouns and short verbs |
| Excess you/we | "you" or "we" several times in one paragraph, or an authorial "I" appearing in the body | Make the people, objects or events the subject |
| Curse of knowledge | An acronym, jargon or an "obviously" hides a step a first-time reader lacks | Fill in the step; put a concrete example before an abstract statement |
| Overlong sentence | Cannot be read in one breath, or carries two main ideas | Split where the idea turns |
| Translationese (English editions) | Chinese topic-first order ("How fragile it is, the experiment shows"), comma chains of clauses, literal idioms, a heavy noun stack before the subject | Rewrite from meaning, with the agent first and the verb early, and split long chains |
| Spelling / convention drift | colour and color both appear, or the quote style is inconsistent | Follow the project's choice throughout |

Structure:

- Does the opening start from something familiar and set up why we're here, or does it drop the reader into a scene?
- Situation first, then solution, then name?
- With the headings covered, does the text read straight through, so the reader knows why each paragraph is there? If it reads like an outline, rewrite it.
- When telling history or an invention, are events in the order they happened, without jumping ahead and doubling back? (Not needed when explaining a concept or a use.)
- Have numbers, dates and names the reader doesn't need been cut?
- Do the story, history or game outweigh the concept itself? In a course with a story, is the subject the concept or a story character, and has any concept's name been replaced by a story term? Apply the deletion test.
- Do the examples of each core concept mark its edge (by default three or more, including a counterexample; one is enough for an easy concept)?
- Does each heading say what the section covers, and does it contain the concept first named in that section? Check for slogans, "Why X Matters" and metaphor-only headings.
- Does character dialogue lecture, recite definitions or run as neat Q&A?
- Is there meta-language ("in this chapter", "as mentioned"), or any preview of later sections?
- Does the register fit the named audience, with the right sentence length, glossed terms and spelling, and no talking down?
- For an English edition: do facts, sources, ids, answers and numbers match the Chinese exactly?

## 2. AI-voice signals (a run must be fixed; judge a single one in context)

Scan for the signals below. How to judge: if several turn up in one paragraph, or the same pattern turns up paragraph after paragraph, it is a run and must be fixed. A lone occurrence gets a look at whether it earns its place here (a "not X but Y" that really corrects a misconception the reader holds; one em dash that gives a needed pause). If it does, keep it and mark it "kept" in the report.

| Type | How to spot it | Fix |
|---|---|---|
| Antithesis template | Two or three sentences in a row that build up, then knock down ("before it was solved / after it was solved", "beat the champion / couldn't fold a shirt") | Keep one contrast and tell the rest straight, or move the contrasts into different paragraphs |
| Labelling | "This is called X", "This phenomenon has a name: X", "AI that does Y is called Z", with every paragraph running example then definition | Let the name arrive inside the narration, and vary how paragraphs move forward |
| Formulaic opening sentence | The paragraph opens with a short standalone sentence before the real content. It can be an assertion ("This isn't made up."), a signpost ("Now the votes." "Back to the room."), a mini-question ("And the calculator?") or a preview ("First, a game character.") | Delete it and start from the fact, or merge it into the next sentence. After fixing, scan every paragraph's first sentence once more |
| Rhetorical-question opener | The paragraph or section begins with a question the writer then answers | Start from the fact or the scene. A question belongs at the end of a paragraph, answered at once |
| Question at every paragraph end | Each paragraph closes on a question that the next one answers | Keep the ones that really drive the reading and use other transitions for the rest |
| Summary or moral ending | The last sentence restates the paragraph, or "This shows…", "Ultimately…" | Delete it, or end on a question the next paragraph answers |
| One-line punchline paragraph | A paragraph that is a single dramatic sentence | Fold it into a neighbouring paragraph, or cut it |
| Em dash | Used for a dramatic pause or an aside, and piling up | Use commas, full stops or parentheses, or split the sentence |
| AI vocabulary | delve, tapestry, testament, crucial, pivotal, navigate, landscape, realm, unlock, harness, robust, seamless, vibrant, intricate, foster, underscore | Use a plain word, or delete the phrase |
| Contrast frame | "It's not X, it's Y", "not just X but Y", "not only… but also", "more than just", used to manufacture contrast | State Y directly. Keep it when it corrects a misconception the reader really has |
| Tricolon | Lists of three adjectives or clauses for rhythm, especially stacked in a row | Use the real number of items, and break up the rhythm |
| Stock connectives | In other words, Ultimately, In essence, Essentially, It's worth noting that, Interestingly, Notably, Indeed | Delete them and say the content |
| Reader staging | "Imagine you…", "Picture yourself…", "You'll be amazed…" | Describe the thing itself. Use "you" only to invite the reader to try, guess or recall |
| Colon definition | "X: the Y that…" in running prose | Write a full sentence with the concept inside it |
| Inflated stakes / big words | "reshape the future", "holy grail", "crown jewel", "game-changer", "mind-blowing" | Say what actually happened, in plain words |
| Enumeration scaffolding | "Firstly… Secondly… Finally" in narrative prose | Narrate in the real order with real connectives. A numbered list for steps is fine |
| Hedging stack | may, potentially, arguably, to some extent, in some ways, of course, parenthetical disclaimers | Delete them. State real uncertainty once, on the specific claim |
| Suspense signposting, forced uplift | "Flip to the last card and see…"; "just like in life, we all…" | State what the cards show; delete the uplift or give a real example |

## 3. Preferences (project-adjustable; check last)

Look in the project guide first for different settings. If there are none, use SKILL.md "Preferences":

- Any "X: Y" colon headings? More than one question heading? Headings over about 10 words?
- More than one em dash in a paragraph?
- More than two highlighter or emphasis marks of one kind in a paragraph? Any bold in running prose?

Report preference problems as suggestions, separate from principles and signals.

## 4. Report format

One line per issue: `location (section + first 8 words of the sentence) | tier (principle / signal / preference) | type | original | rewrite`. Mark uncertain calls as "possible", and a lone signal judged acceptable as "kept". End with the 3 most frequent types so the writer can search the whole text for them in one go.
